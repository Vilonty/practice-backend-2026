# Booking API — Система бронирования номеров

Веб-программирование | 2026 | Преддипломная практика

---

## О проекте

REST API для системы бронирования номеров в отеле. Проект реализует полный цикл управления номерами, бронированиями, отзывами и пользователями с разграничением прав доступа.

**Стек технологий:**
- Node.js + Express + TypeScript
- PostgreSQL + Sequelize ORM
- JWT аутентификация
- Docker + Docker Compose
- Jest (тестирование)

## Матрица доступа

### Роли пользователей
| Роль | Описание |
|------|----------|
| Гость | Неавторизованный пользователь |
| Пользователь | Авторизованный пользователь (role: 'user') |
| Администратор | Администратор системы (role: 'admin') |

### Условные обозначения
- **Полный доступ** - может выполнять действие
- **Только просмотр** - может видеть, но не изменять
- **Нет доступа** - не может выполнять действие
- **Ограниченный доступ** - только свои записи

| Просмотр своего профиля | `GET /api/v1/auth/me` | Нет доступа | Полный доступ | Полный доступ |
| Просмотр всех пользователей | `GET /api/v1/users` | Нет доступа | Нет доступа | Полный доступ |
| Изменение роли пользователя | `PUT /api/v1/users/:id/role` | Нет доступа | Нет доступа | Полный доступ |

| Поиск с фильтрацией | `GET /api/v1/rooms/search` | Полный доступ | Полный доступ | Полный доступ |

| Удаление (деактивация) | `DELETE /api/v1/rooms/:id` | Нет доступа | Нет доступа | Полный доступ |

### 3. Бронирования (Bookings)

| Действие | Endpoint | Гость | Пользователь | Админ |
|----------|----------|-------|--------------|-------|
| Создание бронирования | `POST /api/v1/bookings` | Нет доступа | Полный доступ | Полный доступ |
| Просмотр своих бронирований | `GET /api/v1/bookings/my` | Нет доступа | Полный доступ | Полный доступ |
| Просмотр всех бронирований | `GET /api/v1/bookings/admin/all` | Нет доступа | Нет доступа | Полный доступ |
| Отмена бронирования | `PUT /api/v1/bookings/:id/cancel` | Нет доступа | Ограниченно (только своё) | Полный доступ |
| Поиск свободных номеров | `GET /api/v1/bookings/available` | Полный доступ | Полный доступ | Полный доступ |
| Расписание номера | `GET /api/v1/bookings/rooms/:roomId/schedule` | Полный доступ | Полный доступ | Полный доступ |
| Статистика | `GET /api/v1/bookings/admin/stats` | Нет доступа | Нет доступа | Полный доступ |

**Правила для бронирований:**
- Пользователь может отменить бронирование только до даты заезда
- Админ может отменить любое бронирование в любое время
- После даты заезда статус автоматически меняется на 'completed'
- Нельзя создать бронирование на пересекающееся время
- Отмена возможна не менее чем за 24 часа до даты заезда

### 4. Отзывы (Reviews)

| Действие | Endpoint | Гость | Пользователь | Админ |
|----------|----------|-------|--------------|-------|
| Создание отзыва | `POST /api/v1/reviews` | Нет доступа | Ограниченно (после проживания) | Полный доступ |
| Просмотр отзывов о номере | `GET /api/v1/reviews/room/:roomId` | Полный доступ | Полный доступ | Полный доступ |
| Просмотр своих отзывов | `GET /api/v1/reviews/my` | Нет доступа | Полный доступ | Полный доступ |
| Редактирование отзыва | `PUT /api/v1/reviews/:id` | Нет доступа | Ограниченно (только свой) | Полный доступ |
| Удаление отзыва | `DELETE /api/v1/reviews/:id` | Нет доступа | Ограниченно (только свой) | Полный доступ |

**Правила для отзывов:**
- Отзыв можно оставить только после завершённого бронирования
- Один пользователь - один отзыв на номер
- Рейтинг от 1 до 5
- Нельзя редактировать или удалять чужие отзывы

## API Endpoints

Базовый URL: `/api/v1`

### Аутентификация
| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/auth/register` | Регистрация нового пользователя |
| POST | `/auth/login` | Вход в систему (получение JWT) |
| GET | `/auth/me` | Информация о текущем пользователе |

### Номера
| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/rooms` | Список всех номеров |
| GET | `/rooms/:id` | Детальная информация о номере |
| GET | `/rooms/search` | Поиск номеров с фильтрацией (пагинация, сортировка) |
| POST | `/rooms` | Создание номера (admin) |
| PUT | `/rooms/:id` | Обновление номера (admin) |
| DELETE | `/rooms/:id` | Деактивация номера (admin) |

### Бронирования
| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/bookings` | Создать бронирование |
| GET | `/bookings/my` | Мои бронирования |
| PUT | `/bookings/:id/cancel` | Отменить бронирование |
| GET | `/bookings/available` | Поиск свободных комнат |
| GET | `/bookings/rooms/:roomId/schedule` | Расписание комнаты на дату |
| GET | `/bookings/admin/all` | Все бронирования (admin) |
| GET | `/bookings/admin/search` | Поиск бронирований (admin) |
| GET | `/bookings/admin/stats` | Статистика (admin) |

### Отзывы
| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/reviews` | Создать отзыв |
| GET | `/reviews/room/:roomId` | Отзывы о комнате |
| GET | `/reviews/my` | Мои отзывы |
| PUT | `/reviews/:id` | Обновить отзыв |
| DELETE | `/reviews/:id` | Удалить отзыв |
