# Матрица доступа (Access Matrix)

## Роли пользователей
| Роль | Описание |
|------|----------|
| **Гость** | Неавторизованный пользователь |
| **Пользователь** | Авторизованный пользователь (role: 'user') |
| **Администратор** | Администратор системы (role: 'admin') |

## Условные обозначения
- ✅ **Полный доступ** - может выполнять действие
- 👁️ **Только просмотр** - может видеть, но не изменять
- ❌ **Нет доступа** - не может выполнять действие
- 🔄 **Ограниченный доступ** - только свои записи

## 3. Бронирования (Bookings)

| Действие | Endpoint | Гость | Пользователь | Админ |
|----------|----------|-------|--------------|-------|
| Создание бронирования | `POST /api/v1/bookings` | ❌ | ✅ | ✅ |
| Просмотр своих бронирований | `GET /api/v1/bookings/my` | ❌ | ✅ | ✅ |
| Просмотр всех бронирований | `GET /api/v1/bookings` | ❌ | ❌ | ✅ |
| Просмотр конкретного бронирования | `GET /api/v1/bookings/:id` | ❌ | 🔄 (только своё) | ✅ |
| Отмена бронирования | `PUT /api/v1/bookings/:id/cancel` | ❌ | 🔄 (только своё) | ✅ |
| Подтверждение бронирования | `PUT /api/v1/bookings/:id/confirm` | ❌ | ❌ | ✅ |
| Просмотр расписания номера | `GET /api/v1/rooms/:id/schedule` | ✅ | ✅ | ✅ |
| Поиск свободных номеров | `GET /api/v1/rooms/available` | ✅ | ✅ | ✅ |

### Правила для бронирований:
- Пользователь может отменить бронирование **только до даты заезда**
- Админ может отменить **любое** бронирование в любое время
- После даты заезда статус автоматически меняется на `completed`
- Нельзя создать бронирование на пересекающееся время

## 4. Отзывы (Reviews)

| Действие | Endpoint | Гость | Пользователь | Админ |
|----------|----------|-------|--------------|-------|
| Создание отзыва | `POST /api/v1/reviews` | ❌ | 🔄 (только после проживания) | ✅ |
| Просмотр отзывов о номере | `GET /api/v1/rooms/:id/reviews` | ✅ | ✅ | ✅ |
| Редактирование своего отзыва | `PUT /api/v1/reviews/:id` | ❌ | 🔄 (только свой) | ✅ |
| Удаление отзыва | `DELETE /api/v1/reviews/:id` | ❌ | 🔄 (только свой) | ✅ |
| Просмотр всех отзывов | `GET /api/v1/reviews` | ❌ | ❌ | ✅ |

### Правила для отзывов:
- Отзыв можно оставить **только после завершённого бронирования** (status: 'completed')
- Один пользователь - один отзыв на номер
- Рейтинг от 1 до 5

## 6. Коды ответов API

| Ситуация | HTTP код | Описание |
|----------|----------|----------|
| Успешный запрос | 200 | OK |
| Создано | 201 | Created |
| Некорректные данные | 400 | Bad Request |
| Не авторизован | 401 | Unauthorized |
| Нет прав | 403 | Forbidden |
| Не найдено | 404 | Not Found |
| Конфликт (пересечение времени) | 409 | Conflict |

## 7. Примеры проверки прав в коде

```typescript
// Пример: пользователь может видеть только свои бронирования
if (req.user.role !== 'admin' && booking.user_id !== req.user.id) {
  throw new AppError('Access denied', 403);
}

// Пример: только админ может создавать номера
if (req.user.role !== 'admin') {
  throw new AppError('Admin access required', 403);
}

// Пример: отзыв только после проживания
if (booking.status !== 'completed') {
  throw new AppError('Can only review completed bookings', 400);
}
